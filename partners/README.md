# Partner logos

Drop each partner's logo here (SVG preferred, otherwise PNG with a transparent
background, about 400 px wide) and add one line to the `partners` list in
`config.js`:

    { name: 'Example AI', file: 'partners/example-ai.svg', url: 'https://example.com' },

The page draws them in a grid, greyscale until hovered. With an empty list the
section reads "Partners to be announced" with a contact link.
